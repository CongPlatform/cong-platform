# Pulso V3 — imagens de demonstração

Oito arquivos locais `pulso-v3-*.webp` foram produzidos a partir de cenas ilustrativas geradas por IA, incluindo recortes de composições autorais do Pulso e de outras cenas educacionais. Algumas imagens são menores e devem ser substituídas por fotos institucionais de boa resolução antes da publicação. Não são fotografias de uma ONG real, nem comprovam a realização de eventos, atividades ou resultados. Cada elemento de imagem é editável por assetId; a hero é uma imagem de fundo substituível pelo editor de seção.

Nenhum dado de desempenho, horário ou contato neste modelo deve ser interpretado como factual. Gráficos identificados como fictícios precisam ser substituídos pela organização antes de publicar.
