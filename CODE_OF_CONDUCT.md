# Código de Conduta — CONG

[English version below](#code-of-conduct--cong)

A **CONG — Construtor Operacional para ONGs** é um projeto com proposta colaborativa e open-source, voltado para impacto social e apoio a organizações sociais.

Para manter um ambiente respeitoso, seguro e produtivo, todos os participantes devem seguir este código de conduta.

## Nosso compromisso

Nos comprometemos a manter um ambiente aberto, acolhedor e respeitoso para todos, independentemente de nível de experiência, formação, idade, aparência, origem, idioma ou área de atuação.

A CONG deve ser um espaço onde estudantes, desenvolvedores, designers, voluntários, ONGs e demais colaboradores possam participar de forma construtiva.

## Comportamentos esperados

São exemplos de comportamentos esperados:

* Tratar outras pessoas com respeito
* Ser paciente com iniciantes
* Fazer críticas de forma construtiva
* Explicar decisões técnicas com clareza
* Aceitar opiniões diferentes
* Colaborar para melhorar o projeto
* Manter discussões focadas no projeto
* Reconhecer contribuições de outras pessoas

## Comportamentos não aceitos

Não serão aceitos:

* Ataques pessoais
* Ofensas, humilhações ou provocações
* Comentários preconceituosos ou discriminatórios
* Assédio de qualquer tipo
* Exposição indevida de dados pessoais
* Desrespeito a ONGs, beneficiários, voluntários ou colaboradores
* Uso do projeto para fins maliciosos
* Discussões agressivas ou fora do propósito do projeto

## Responsabilidade dos colaboradores

Todos os colaboradores devem ajudar a manter um ambiente saudável.

Caso encontre um problema, tente agir com respeito e, se necessário, comunique os responsáveis pelo projeto.

## Aplicação

Os responsáveis pelo projeto poderão remover comentários, issues, Pull Requests ou contribuições que violem este código de conduta.

Em casos mais graves, uma pessoa poderá ser impedida de participar do projeto.

## Objetivo

Este código de conduta existe para proteger a comunidade e garantir que a CONG cresça como um projeto técnico, social e colaborativo.

# Code of Conduct — CONG

[Versão em português acima](#código-de-conduta--cong)

**CONG — Operational Builder for NGOs** is a collaborative and open-source-oriented project focused on social impact and support for social organizations.

To maintain a respectful, safe, and productive environment, all participants must follow this code of conduct.

## Our commitment

We are committed to maintaining an open, welcoming, and respectful environment for everyone, regardless of experience level, background, age, appearance, origin, language, or field of work.

CONG should be a space where students, developers, designers, volunteers, NGOs, and other contributors can participate constructively.

## Expected behavior

Examples of expected behavior include:

* Treating others with respect
* Being patient with beginners
* Giving constructive feedback
* Explaining technical decisions clearly
* Accepting different opinions
* Collaborating to improve the project
* Keeping discussions focused on the project
* Recognizing other people’s contributions

## Unacceptable behavior

The following behaviors are not accepted:

* Personal attacks
* Insults, humiliation, or provocation
* Prejudiced or discriminatory comments
* Harassment of any kind
* Improper exposure of personal data
* Disrespect toward NGOs, beneficiaries, volunteers, or contributors
* Use of the project for malicious purposes
* Aggressive discussions or discussions unrelated to the project’s purpose

## Contributor responsibility

All contributors should help maintain a healthy environment.

If you find a problem, try to act respectfully and, if necessary, contact the project maintainers.

## Enforcement

Project maintainers may remove comments, issues, Pull Requests, or contributions that violate this code of conduct.

In more serious cases, a person may be prevented from participating in the project.

## Purpose

This code of conduct exists to protect the community and ensure that CONG grows as a technical, social, and collaborative project.
